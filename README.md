AuditMyTime.RPG is a cutting-edge, privacy-first, gamified digital focus extension built for Google Chrome (Manifest V3). It completely reimagines traditional website blockers by replacing punitive restrictions with an engaging role-playing game (RPG) resource management loop.

Instead of frustrating users with rigid, unbreakable blocks that force them to disable their tools, AuditMyTime turns mindful productivity into an active resource economy:

The Focus Mana Ledger: Users start with a pool of Focus Mana. Visiting distracting sites (like YouTube, Instagram, or Twitter/X) drains this currency.

The Riddle Gateway: When Mana hits zero, restricted paths lock down. To restore access or earn emergency time, users must solve coding and logical reasoning puzzles.

On-Device AI Coaching: Powered locally by Gemini Nano (window.ai), the extension acts as an offline intelligence terminal—synthesizing dynamic engineering riddles and serving as a private AI chat coach.

The Crypt Vault Security Layer: Employs local Web Crypto (SHA-256) signature hashing to prevent developer console manipulation or score tampering, ensuring strict data integrity.

Zero Cloud Telemetry: Because all state processing, encryption, and AI prompting run entirely on-device, zero private browsing telemetry or search data ever leaks to a remote server.

In short, AuditMyTime.RPG transforms digital discipline from a tedious chore into an immersive, production-grade technical showcase for modern web architecture.
